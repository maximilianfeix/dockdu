### Finding fixed during validation

- **P1: image reclaimable labelled "as df counts it" was false on Engine 28.**
  - docker CLI 28 prints LayersSize − Σ unique bytes of images in use, which counts shared base layers of images in use as reclaimable: 8.54 MB in the demo against the API's 0 B.
  - dockdu keeps the API figure and now labels it "reclaimable per the Docker API" (edd226c).
  - The build cache label stays: it matched df on both engines (96 B and 12.29 kB).
